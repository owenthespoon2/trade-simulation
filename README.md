# Trade Simulation

A simulation of settlements, trade and caravans on a real map, growing towards a slow, multiplayer merchant game ("The Gilded Road"). The world is a formula: the height of the land at any point is calculated, and settlements, farms and trade routes sit on top of it.

It's being rebuilt in TypeScript, one small, fully understood piece at a time.
